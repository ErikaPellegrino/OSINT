## 🛡️ Operational Security (OPSEC)

For each exercise, operational risk and target complexity were assessed prior to execution. The level of OPSEC, sock accounts, and anonymization techniques applied vary based on the specific scenario requirements.

## ✅ Evidence Validation

Verification techniques were applied based on context and data availability. Exercises are documented with verified proof where possible, while theoretical or limited-scope scenarios are explicitly flagged.
